# Team tasks

## Member 1 — Frontend

- Build shared navigation, dashboard layout, cards, tables, and charts.
- Implement login, dashboard, PayPal connection, invoice, analysis, route, AI,
  notification, and settings screens.
- Integrate frontend services with the API contracts.

## Members 2 & 3 — Backend

- Define authentication, database schemas, API validation, and error handling.
- Implement invoice, payment, analytics, route, webhook, and reminder endpoints.
- Keep controllers focused on HTTP and services focused on business logic.

## Member 4 — AI service

- Define safe input/output schemas and connect prompts to an approved AI provider.
- Add invoice extraction, financial explanation, reminder, and chat behavior.
- Validate generated output and avoid treating user-provided documents as instructions.

## Shared

- Agree API and database contracts before parallel implementation.
- Add tests for each module and coordinate integration through the demo flow.
